# 委任のモデル・経路設定

通常の委任ではこのファイルを直接確認し、管理スキルの全文は読みません。ユーザーの直近の指定を優先し、日付付きの申告を現在の料金や利用可否の保証にしません。担当設定は `~/.codex/agents/` と利用可能なツールを照合し、設定値や起動引数だけで実行時の一致を断言しません。

## 委任・相談先

- 通常の相談・レビュー・調査・作業分担は、必要な時だけCodex内のサブエージェントへ渡します。Claude・Sonnet・Fable等のモデル名だけでClaude Code CLIやagmsgを選びません。実際に利用できるモデル・推論強度を確認し、同じ担当へ追加指示を送り、標準の完了通知と結果回収を使います。独立した継続担当は、本人が新規／別スレッドを明示した時にCodexの専用ツールで作成・連絡します。作成・他スレッドへの送信に必要な許可は保ち、会話が長いだけで新規スレッドを増やしません。
- agmsgは、本人の明示指定、Codex外のCLI・アプリ・端末で動く既存セッションへの連絡、または指定モデル・実行環境などの必要条件をCodex内の利用可能かつ許可された経路では満たせない場合に使います。既にagmsgで進めている同じ担当との会話は履歴を分断せず継続します。新たな一般相談までその経路へ固定しません。常時起動の担当群、空振りの定期モデル呼出し、不要な返信の往復は作りません。自動の結果通知・受信対応は利用しますが、待受と実際のモデル呼出しを分けて費用を評価します。

- 通常の委任先はClaude Sonnet、GPT-6 Luna、GPT-6.1 Terra、DeepSeek V4.1 Flash、Devin SWE-2、OpenCode提供モデルです。Lunaに固定せず、仕事に応じて使い分けます。2026-11-03指定でSonnet・Terra・DeepSeekもmaxまで利用でき、各担当設定はmaxです。これはultraの許可ではありません。DeepSeek V4.1 Flashは同日の本人申告に従い使い放題として活用します。OpenCode経由で別の高コストモデルを使う許可ではありません。他のモデルは必要性と理由を示して明示許可を得ます。この制限はCLI等の別経路にも適用します。GPT-6 Lunaは `agents/luna.toml` のmaxを維持します（2026-10-23指定）。軽量な仕事でも独断で下げません。Astraの推論強度highは使いません。グローバルメモリ編集は `$edit-global-memory` のAstra・low担当への委任と費用許可の例外に従います。SWE-2はMaxを既定とし、実作業には `$devin-worker` を使います。2026-09-16のユーザー申告ではDevinは使い放題なので積極活用しますが、不要な委任を避け、条件が変われば見直します。個別の利用中止を全般の禁止へ広げません。

相談やFableの監修では [consultation-models.md](consultation-models.md) の該当条件だけを追加で確認します。他スレッド・継続・監視の管理が必要な時は [SKILL.md](../SKILL.md) から該当手順へ進みます。
